# 사용 가이드

[English](user-guide.md)

## 로그인

- 관리자가 보낸 초대 링크를 열어 계정을 만듭니다.
- 비밀번호를 잊었다면 관리자에게 재설정 링크를 요청하세요. 하루 안에 한 번 쓸 수 있습니다.
- 비밀번호와 화면 언어는 왼쪽 아래 **내 이름** → **내 계정**에서 바꿉니다. 언어와 테마(시스템 설정·라이트·다크, 이름 옆 해/달 버튼으로도 전환)는 계정에 저장되므로 어느 기기에서 로그인해도 같게 보입니다. 로그인 전에는 로그인 화면 아래에서 고를 수 있습니다.

## 홈

로그인하면 **홈**으로 들어옵니다.

- **최근 본 페이지**: 마지막으로 연 페이지들.
- **나에게 온 소식**: 누군가 나를 언급했거나, 내 댓글에 답했거나, 내가 만든 페이지에 댓글을 단 곳.
- **새로 만든 페이지**: 볼 수 있는 스페이스에서 최근 만들어진 페이지.
- 위쪽 버튼으로 템플릿에서 페이지를 만들거나 **가져오기**를 엽니다.

스페이스 이름 옆 종 아이콘에 읽지 않은 알림 수가 표시되고, 누르면 해당 페이지로 갑니다.

## 스페이스와 페이지

**스페이스**는 가장 큰 단위로, 보통 팀마다 하나씩 둡니다. 스페이스 안의 페이지는 트리를 이룹니다.

| 하려는 일 | 방법 |
|---|---|
| 스페이스 전환·생성 | 왼쪽 위 스페이스 이름 클릭 |
| 스페이스 공개 범위 변경 | 스페이스 이름 → **스페이스 설정** (스페이스 관리자) |
| 페이지 만들기 | 사이드바의 **새 페이지**, 또는 **홈**의 템플릿 |
| 하위 페이지 만들기 | 사이드바에서 페이지에 마우스를 올리고 **+** |
| 페이지 이동·순서 변경 | 사이드바에서 끌어다 놓기. 페이지 가운데에 놓으면 그 안으로, 위·아래 가장자리에 놓으면 앞·뒤로 갑니다 |
| 페이지 삭제 | **⋯ → 휴지통으로 이동**. 하위 페이지도 같이 갑니다. 몇 초 동안 **실행 취소**가 뜹니다 |
| 페이지 복원 | 사이드바 **휴지통** → **복원** |

### 템플릿

**홈**에서 빈 페이지, 주간보고, 회의록, 기술 문서로 시작할 수 있습니다. 템플릿 내용은 일반 페이지 내용이라 자유롭게 고치면 됩니다.

## 작성

입력을 멈추고 1초쯤 지나면 **자동으로 저장**됩니다. 상단에 *저장 중…* 다음 *저장됨*이 표시됩니다. 바로 저장하려면 **⌘S** / **Ctrl+S**를 누르세요.

### 블록: `/` 입력

빈 줄에서 `/`를 입력하면 블록 메뉴가 뜹니다. 이어서 입력하면 걸러집니다(`/표`, `/코드`, `/table` 모두 됩니다).

| 블록 | 참고 |
|---|---|
| 제목 1~3 | 오른쪽 **목차**에 나타납니다 |
| 글머리·번호·할 일 목록 | Tab / Shift+Tab으로 들여쓰기 |
| 표 | 표 안을 클릭하면 메뉴가 뜹니다: 행·열 추가·삭제, 머리글 행. 병합은 셀을 드래그(또는 Shift+클릭)로 선택한 뒤 **셀 병합**, 병합된 셀에서는 **셀 분할** |
| 정보·주의·완료·위험 패널 | 패널 아이콘을 누르면 종류가 바뀝니다 |
| 코드 블록 | 위에 뜨는 메뉴에서 언어를 고릅니다 |
| 인용, 구분선 | |
| 이미지·파일 | 페이지에 바로 붙여넣거나 끌어다 놓아도 됩니다 |

### 서식

글자를 선택하면 서식 메뉴가 뜹니다: 굵게, 기울임, 취소선, 인라인 코드, 형광펜, 링크, 제목.

입력하면서 Markdown식 단축 입력도 쓸 수 있습니다.

| 입력 | 결과 |
|---|---|
| `# ` `## ` `### ` | 제목 |
| `- ` 또는 `* ` | 글머리 목록 |
| `1. ` | 번호 목록 |
| `[ ] ` | 할 일 |
| `> ` | 인용 |
| `` ``` `` | 코드 블록 |
| `---` | 구분선 |

| 단축키 | 동작 |
|---|---|
| ⌘K / Ctrl+K | 검색 |
| ⌘S / Ctrl+S | 바로 저장 |
| ⌘B, ⌘I | 굵게, 기울임 |
| 제목에서 Enter | 본문으로 이동 |
| 댓글에서 ⌘Enter | 등록 |

### 이미지와 파일

붙여넣기, 끌어다 놓기, 또는 `/` → **이미지·파일**. PNG, JPEG, GIF, WebP 이미지는 페이지 안에 보이고, 나머지 파일은 내려받는 링크로 들어갑니다. 파일당 50MB까지입니다.

## 두 사람이 같은 페이지를 고칠 때

먼저 저장한 쪽이 반영됩니다. 나중 사람에게는 *다른 사람이 먼저 수정했습니다*가 뜨고 자동 저장이 멈추므로, 내용이 덮어써지지 않습니다. 내 수정 내용은 이 기기에 보관됩니다. **새로 불러오기**를 누르면 **복원** 버튼이 뜨고, 누르면 내 수정이 그 위에 반영되며 상대방 버전은 이력에 남습니다. 실시간 공동 편집은 계획되어 있습니다.

## 연결이 끊겼을 때

서버에 저장되지 못한 수정은 브라우저에 보관됩니다. 상단에 *오프라인*이 표시되고, 연결이 돌아오면 알아서 저장합니다. 그 전에 탭을 닫았다면, 다음에 페이지를 열 때 복원할지 묻습니다.

삭제한 댓글도 페이지처럼 삭제 직후 **실행 취소**로 되살릴 수 있습니다.

## 이력

상단의 **이력**에 이전 버전이 나옵니다. 같은 사람이 10분 안에 저장한 내용은 한 버전으로 묶입니다. **이 버전으로 되돌리기**를 누르면 되돌아가고, 지금 내용도 이력에 남습니다.

## 댓글

댓글은 페이지 맨 아래에 있습니다. 댓글 아래에 답글을 달고, 끝난 일은 **해결**로 표시하세요. 해결된 댓글은 펼치기 전까지 숨겨집니다.

## 멘션과 알림

페이지나 댓글에서 `@`를 입력하고 사람을 고르세요. 페이지를 저장하거나 댓글을 등록하면 그 사람에게 알림이 갑니다. 단, 그 페이지를 볼 수 있는 사람에게만 갑니다. 내 댓글에 답글이 달리거나 내가 만든 페이지에 댓글이 달려도 알림을 받습니다.

## 스페이스를 볼 수 있는 사람

스페이스마다 멤버가 아닌 사람에게 주는 기본 권한이 있습니다.

| 설정 | 의미 |
|---|---|
| 모두 편집 가능 | 로그인한 모든 사람이 보고 편집 (기본값) |
| 모두 보기 가능 | 모두 읽을 수 있고, **편집**·**관리자** 멤버만 페이지를 바꿀 수 있음 |
| 비공개 | 멤버만 볼 수 있음. 다른 사람의 스페이스 목록, 검색, 홈 어디에도 나오지 않음 |

멤버에게는 **관리자**(스페이스 관리), **편집**, **보기**를 줍니다. 스페이스를 만든 사람이 관리자가 됩니다. 페이지는 스페이스보다 더 열릴 수 없습니다. 보기 전용 스페이스에서 페이지 제한은 접근을 더 좁힐 수는 있어도 넓힐 수는 없습니다.

## 페이지를 볼 수 있는 사람

기본으로는 로그인한 모든 사람이 모든 페이지를 보고 고칠 수 있습니다. 제한하려면:

1. 상단의 **접근 권한**을 누릅니다.
2. **지정한 사용자만**을 고릅니다.
3. 사람을 추가하고 각각 **보기** 또는 **편집**을 정합니다.

규칙:

- 목록에 없는 사람은 그 페이지를 어디서도 찾을 수 없습니다. 사이드바, 검색, 최근 목록, 휴지통, 댓글, 이력, 첨부 모두 마찬가지입니다.
- 제한된 페이지 **안의** 페이지는 제한을 물려받습니다. 위쪽의 모든 제한 페이지에서 허용되어야 볼 수 있습니다.
- 제한을 건 사람은 항상 편집 권한을 유지합니다.
- **관리자는 모든 페이지를 열 수 있습니다.** 아무도 열 수 없는 페이지를 풀어 주기 위해서입니다.
- 제한된 페이지에는 사이드바와 상단에 자물쇠가 표시됩니다.

## 검색

**⌘K** / **Ctrl+K**를 누르거나 **검색**을 클릭하면 빠른 검색이 열리고, 입력하는 대로 가장 잘 맞는 페이지가 나옵니다. **Enter**는 선택한 페이지를 열고, **⌘Enter**(또는 **전체 결과 보기**)는 검색 페이지를 엽니다.

검색 페이지는 입력한 단어가 **모두** 들어 있는 페이지를 찾습니다. 제목에서 찾은 것이 먼저 나오고, 결과마다 위치(경로)와 일치하는 문장을 보여 줍니다. 다음으로 좁힐 수 있습니다.

| 필터 | 선택지 |
|---|---|
| 스페이스 | 특정 스페이스 또는 전체 |
| 마지막 수정자 | 사람 지정 |
| 수정일 | 최근 1주, 1개월, 1년 |
| 검색 범위 | 제목과 본문, 또는 제목만 |
| 정렬 | 관련도순 또는 최신순 |

주소창에 검색어와 필터가 남으므로, 검색을 즐겨찾기하거나 링크로 공유할 수 있습니다. 결과에는 볼 권한이 있는 페이지만 나옵니다.

## 가져오기와 내보내기

**가져오기**(홈, 스페이스 메뉴, 또는 페이지의 **⋯ → 이 페이지 아래로 가져오기**)는 Markdown, HTML, 텍스트 파일이나 이들의 ZIP을 받습니다.

- Pagehouse 내보내기: 페이지 계층, 첨부, 링크까지 그대로 복원
- Notion "Markdown & CSV" 내보내기: 폴더는 하위 페이지로, 이미지는 업로드
- Confluence "HTML" 스페이스 내보내기: 경로(breadcrumb)로 페이지 계층을 복원하고, 첨부는 업로드하며, 정보·경고 매크로는 패널로 변환

가져오기는 새 페이지만 추가하고 기존 페이지는 바꾸지 않습니다.

**내보내기**: 페이지의 **⋯ → 페이지와 하위 페이지 내보내기 (.zip)** 또는 스페이스 메뉴의 **스페이스 내보내기 (.zip)**는 페이지 계층대로 폴더를 만든 Markdown 파일과 첨부, 그대로 다시 가져올 수 있는 `pagehouse.json`을 내려받습니다. 볼 수 있는 페이지만 들어갑니다. **⋯ → Markdown으로 내보내기**는 한 페이지만, **⋯ → 인쇄 / PDF 저장**은 인쇄 창을 엽니다.

## 관리자용

사이드바의 **관리**에는 탭이 두 개 있습니다.

**개요**: 디스크 및 선택적 **저장 한도** 대비 사용량(DB와 첨부), 마지막 자동 백업, 콘텐츠 수, 일별 편집, 큰 파일. 한도에 도달하면 새 파일 업로드는 거부되지만 글은 항상 저장됩니다.

**사용자**:

| 하려는 일 | 방법 |
|---|---|
| 초대 | **멤버 초대 링크** 또는 **관리자 초대 링크**를 만들어 전달. 7일 안에 한 번 쓸 수 있습니다 |
| 역할 변경 | 역할 열 |
| 접근 차단 | **비활성화**. 즉시 로그아웃됩니다. **활성화**하면 다시 들어올 수 있습니다 |
| 비밀번호 재설정 | **비밀번호 재설정 링크**를 만들어 전달. 하루 안에 한 번 쓸 수 있습니다 |

자기 역할을 바꾸거나 자기 계정을 비활성화할 수는 없습니다. 그래서 관리자가 최소 한 명은 항상 남습니다.
