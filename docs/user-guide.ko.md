# 사용 가이드

[English](user-guide.md)

## 로그인과 내 계정

- 관리자가 보낸 **초대 링크**를 열어 계정을 만듭니다. 회사 SSO가 설정되어 있으면 로그인 화면의 SSO 버튼을 씁니다.
- 비밀번호를 잊었다면:
  - 로그인 화면의 **비밀번호를 잊으셨나요?**에서 재설정 메일을 받습니다. 링크는 1시간 동안 한 번만 쓸 수 있습니다.
  - 이 버튼이 없다면 메일이 설정되지 않은 상태이니 관리자에게 재설정 링크나 임시 비밀번호를 요청하세요.
  - 임시 비밀번호로 로그인하면 바로 새 비밀번호를 정해야 합니다.
- **내 계정**(왼쪽 아래 내 이름)에서 바꿀 수 있는 것:
  - 이름과 프로필 사진: 사진은 정사각형으로 잘려 사이드바·댓글·멘션·알림에 표시됩니다.
  - 테마(시스템 설정·라이트·다크)와 화면 언어(한국어·English): 계정에 저장되어 어느 기기에서나 같게 보입니다.
  - 비밀번호, 개인 API 토큰(아래 [AI 에이전트](#ai-에이전트-mcp)), 메일 알림(메일이 설정된 경우).

## 홈과 사이드바

로그인하면 **홈**으로 들어옵니다.

- **최근 본 페이지**: 내가 마지막으로 연 페이지
- **나에게 온 소식**: 나를 언급했거나, 내 댓글에 답했거나, 내가 지켜보는 페이지가 바뀐 곳
- **새로 만든 페이지**: 볼 수 있는 스페이스에서 최근 만들어진 페이지
- 위쪽 버튼: 템플릿으로 새 페이지 만들기, **가져오기**

**사이드바 구성 (위에서부터)**
- 스페이스 전환
- 검색
- 홈·휴지통
- **즐겨찾기**
- **최근 본 페이지**
- 페이지 트리

사이드바 오른쪽 위의 패널 버튼이나 **⌘\\** / **Ctrl+\\**로 사이드바를 접고 다시 펼칠 수 있습니다(이 브라우저에 기억됩니다). 사이드바 오른쪽 경계를 끌면 폭을 넓힐 수 있습니다. 화면의 40%까지 넓어지되 본문은 최소 720px을 남기고, 경계를 더블클릭하면 기본 폭으로 돌아갑니다.

스페이스 이름 옆 종 아이콘에 읽지 않은 알림 수가 표시됩니다. 누가 나를 언급하거나, 내 댓글에 답하거나, 내 페이지에 댓글을 달거나, 내가 구독한 페이지를 고치면 알림이 옵니다.
- **이메일**: 서버에 메일이 설정돼 있으면 읽지 않은 알림을 몇 분 뒤 한 통으로 묶어 보냅니다. **설정**에서 끌 수 있습니다.
- **채팅 도구**: **설정 → 채팅 웹훅으로 알림 받기**에 Slack, Mattermost, Microsoft Teams, Google Chat, Discord의 수신 웹훅 주소를 넣고 **테스트 보내기**를 누른 뒤 **저장**합니다. 내부망 주소는 관리자가 허용해 둔 경우(`WEBHOOK_ALLOW`)에만 쓸 수 있습니다.

## 스페이스와 페이지

**스페이스**는 가장 큰 단위로, 보통 팀마다 하나씩 둡니다. 스페이스 안의 페이지는 트리를 이룹니다.

| 하려는 일 | 방법 |
|---|---|
| 스페이스 전환·생성 | 왼쪽 위 스페이스 이름 클릭 |
| 스페이스 공개 범위·멤버 | 스페이스 이름 → **스페이스 설정** (스페이스 관리자) |
| 페이지 만들기 | 사이드바의 **새 페이지**, **홈**의 템플릿 |
| 하위 페이지 만들기 | 트리에서 페이지 옆 **+** |
| 페이지 메뉴 | 트리에서 페이지 옆 **⋯**: 하위 페이지 추가, 링크 복사, 사본 만들기, 하위 페이지까지 사본 만들기, 휴지통으로 이동 |
| 이동·순서 변경 | 트리에서 끌어다 놓기. 페이지 가운데에 놓으면 그 안으로, 위·아래 가장자리에 놓으면 앞·뒤로 |
| 삭제·복원 | **⋯ → 휴지통으로 이동**(하위 페이지 포함, 몇 초간 **실행 취소**). 되살리기는 사이드바 **휴지통 → 복원** |
| 즐겨찾기 | 페이지 상단 ☆. 사이드바 **즐겨찾기**에 모입니다 |
| 제목 이모지 | 제목 위에 마우스를 올리면 나오는 **아이콘 추가**. 트리와 즐겨찾기에도 보입니다 |
| 라벨 | 제목 아래 **라벨 추가**. 라벨을 누르면 같은 라벨의 페이지가 검색됩니다 |
| 지켜보기 | 상단 **지켜보는 중**. 내가 만든 페이지는 자동으로 지켜봅니다. 바뀌면 알림이 옵니다 |

- 사본은 원본 옆에 "제목 (사본)"으로 생깁니다.
- 사본에는 본문, 첨부, 라벨, 이모지와 **열람 제한**이 같이 복사되므로 사본을 만들어도 볼 수 있는 사람이 늘지 않습니다.

### 템플릿

- **홈**에서 빈 페이지, 주간보고, 회의록, 기술 문서로 시작할 수 있습니다.
- 자주 쓰는 형식이 있으면 페이지 **⋯ → 템플릿으로 저장**으로 우리 팀 템플릿을 만듭니다. 이 스페이스에서만 쓸지, 모든 스페이스에서 쓸지 고를 수 있습니다.

## 작성

입력을 멈추면 **자동으로 저장**됩니다. 바로 저장하려면 **⌘S** / **Ctrl+S**.

### 툴바와 `/` 메뉴

편집할 수 있는 페이지에는 위쪽에 **툴바**가 있습니다. 스크롤해도 따라옵니다.

| 툴바 묶음 | 기능 |
|---|---|
| 편집 | 실행 취소·다시 실행 |
| 글 스타일 | 본문, 제목 1~3 |
| 글자 서식 | 굵게, 기울임, 취소선, 코드, 형광펜 |
| 목록 | 글머리, 번호, 할 일 |
| 넣기 | 표, 이미지·파일, 코드 블록 |
| **+ 삽입** | 패널, 다이어그램, 인용, 구분선 등 모든 블록 |

빈 줄에서 `/`를 입력해도 같은 블록 메뉴가 뜹니다(`/표`, `/코드`, `/table` 모두 됩니다).

| 블록 | 참고 |
|---|---|
| 제목 1~3 | 오른쪽 **목차**에 나타납니다 |
| 글머리·번호·할 일 목록 | Tab / Shift+Tab으로 들여쓰기 |
| 표 | 표 안을 클릭하면 메뉴: 행·열 추가·삭제, 머리글 행, 셀 병합(드래그나 Shift+클릭으로 선택)·분할, 셀 배경색 |
| 정보·주의·완료·위험 패널 | 패널 아이콘을 누르면 종류가 바뀝니다 |
| 코드 블록 | 위에 뜨는 메뉴에서 언어를 고릅니다(Bash, Python, Go, Java부터 PHP, Ruby, Swift, PowerShell까지 45개쯤). 마우스를 올리면 오른쪽 위에 **복사** 버튼 |
| 다이어그램 | Mermaid 문법으로 쓰면 아래에 그림이 그려집니다 |
| 링크 카드 | 빈 줄에 URL을 붙여 넣으면 제목·설명·이미지가 담긴 카드가 됩니다 |
| 이미지·파일 | 붙여넣거나 끌어다 놓아도 됩니다. 이미지는 페이지 안에 보이고, 오른쪽 아래 모서리를 끌어 크기를 바꿉니다(더블클릭하면 원래 크기). 이미지 아래에 캡션도 쓸 수 있습니다. 나머지 파일은 내려받는 링크로. 파일당 50MB |

글자를 선택하면 서식 메뉴가 뜹니다: 굵게, 기울임, 취소선, 코드, 형광펜, **링크**, **댓글**, 제목.

| 입력 | 결과 |
|---|---|
| `# ` `## ` `### ` | 제목 |
| `- ` / `1. ` / `[ ] ` | 글머리 / 번호 / 할 일 |
| `> ` / `` ``` `` / `---` | 인용 / 코드 블록 / 구분선 |
| `@` | 사람 멘션 |

| 단축키 | 동작 |
|---|---|
| ⌘K / Ctrl+K | 검색 |
| ⌘S / Ctrl+S | 바로 저장 |
| ⌘B, ⌘I | 굵게, 기울임 |
| ⌘Z / ⌘⇧Z | 실행 취소 / 다시 실행 |
| 제목에서 Enter | 본문으로 이동 |
| 댓글에서 ⌘Enter | 등록 |

## 함께 편집하기

- 같은 페이지를 여러 사람이 동시에 열면 **실시간 공동 편집**이 됩니다.
  - 다른 사람의 커서와 이름이 보입니다.
  - 동시에 입력해도 서로 덮어쓰지 않습니다.
  - 제목도 함께 바뀝니다.
- 연결이 끊기면 수정 내용을 브라우저에 보관했다가 연결이 돌아오면 저장합니다. 그 전에 탭을 닫았다면 다음에 페이지를 열 때 복원할지 묻습니다.

## 이력

상단의 **이력**에 이전 버전이 나옵니다. 같은 사람이 10분 안에 저장한 내용은 한 버전으로 묶입니다.

- **변경 내용**: 그 버전에서 바뀐 줄을 보여 줍니다.
- **이 버전으로 되돌리기**: 그 버전으로 돌아갑니다. 지금 내용도 이력에 남습니다.

## 댓글

- **페이지 댓글**: 페이지 맨 아래에 있습니다. 답글을 달 수 있고 끝난 일은 **해결**로 표시합니다. 해결된 댓글은 펼치기 전까지 숨겨집니다.
- **인라인 댓글**: 본문 일부를 선택하고 💬를 누르면 그 부분이 강조되면서 댓글이 달립니다. 강조된 곳을 누르면 해당 댓글로 이동합니다.
- **해결 처리**: 댓글을 쓴 사람이나 페이지를 편집할 수 있는 사람이 할 수 있습니다.
- **삭제한 댓글**: 삭제 직후 **실행 취소**로 되살릴 수 있습니다.

## 멘션과 알림

페이지나 댓글에서 `@`를 입력하고 사람을 고르면 그 페이지를 볼 수 있는 사람에게만 알림이 갑니다.

알림이 오는 경우:
- 내 댓글에 답글이 달릴 때
- 내가 만든 페이지에 댓글이 달릴 때
- 내가 지켜보는 페이지가 바뀔 때

메일이 설정되어 있으면 몇 분 동안 읽지 않은 알림을 한 통으로 묶어 보냅니다. 메일 알림은 **내 계정**에서 끌 수 있습니다.

## 스페이스를 볼 수 있는 사람

스페이스마다 멤버가 아닌 사람에게 주는 기본 권한이 있습니다.

| 설정 | 의미 |
|---|---|
| 모두 편집 가능 | 로그인한 모든 사람이 보고 편집 (기본값) |
| 모두 보기 가능 | 모두 읽을 수 있고, **편집**·**관리자** 멤버만 바꿀 수 있음 |
| 비공개 | 멤버만 볼 수 있음. 다른 사람의 스페이스 목록, 검색, 홈 어디에도 나오지 않음 |

- 멤버(사람 또는 **그룹**)에게는 **관리자**(스페이스 관리), **편집**, **보기**를 줍니다.
- 스페이스를 만든 사람이 관리자가 됩니다.
- 페이지를 스페이스보다 넓게 열 수는 없습니다. 페이지 제한은 접근을 좁힐 뿐 넓히지 못합니다.

## 페이지를 볼 수 있는 사람

1. 상단 **접근 권한**을 누릅니다.
2. **지정한 사용자만**을 고릅니다.
3. 사람이나 그룹을 추가하고 **보기** 또는 **편집**을 정합니다.

규칙:

- 목록에 없는 사람에게는 그 페이지가 어디에도 나오지 않습니다. 사이드바, 검색, 최근 목록, 휴지통, 댓글, 이력, 첨부, 내보내기 모두 마찬가지입니다.
- 제한된 페이지 **안의** 페이지는 제한을 물려받습니다. 위쪽의 모든 제한 페이지에서 허용되어야 볼 수 있습니다.
- 제한된 페이지 밖으로 하위 페이지를 옮기면 물려받은 제한이 풀리므로 이런 이동은 **관리자만** 할 수 있습니다.
- 제한을 건 사람은 항상 편집 권한을 유지합니다. **사이트 관리자는 모든 페이지를 열 수 있습니다.**
- 제한된 페이지에는 사이드바와 상단에 자물쇠가 표시됩니다.

## 검색

**빠른 검색:** **⌘K** / **Ctrl+K**나 **검색**을 누르면 열리고 입력하는 대로 가장 잘 맞는 페이지가 나옵니다. **⌘Enter**(또는 **전체 결과 보기**)를 누르면 검색 페이지로 갑니다.

**검색 페이지:**
- 입력한 단어가 **모두** 들어 있는 페이지를 찾습니다.
- "배포를"로 찾아도 "배포는"이 나오도록 한국어 조사를 처리합니다.
- 댓글과 첨부 파일 이름도 검색합니다.

| 필터 | 선택지 |
|---|---|
| 스페이스, 마지막 수정자, 수정일 | 특정 값 또는 전체 |
| 라벨 | 라벨만 골라도(검색어 없이) 그 라벨의 페이지 목록이 나옵니다 |
| 검색 범위 / 정렬 | 제목과 본문·제목만 / 관련도순·최신순 |

검색어와 필터는 주소에 남으므로 즐겨찾기하거나 링크로 공유할 수 있습니다.

## 가져오기

홈의 **가져오기**, 스페이스 메뉴 → **페이지 가져오기…**, 또는 페이지 **⋯ → 이 페이지 아래로 가져오기**에서 엽니다.

파일이나 ZIP을 끌어다 놓거나, 압축을 푼 **폴더를 선택**합니다.

| 원본 | 내보내는 방법 | 옮겨지는 것 |
|---|---|---|
| **Confluence (권장)** | 스페이스 설정 → 내보내기 → CSV | 페이지·폴더 계층과 순서, 첨부(원래 파일명), 라벨, 페이지 간 링크, 코드·패널·펼치기·Jira·drawio·할 일 등 매크로 |
| Confluence | 스페이스 설정 → 내보내기 → HTML | 페이지 계층, 첨부·이미지, 주요 매크로 |
| Confluence 페이지 | 페이지 → 내보내기 → Markdown | 본문(동적 매크로는 링크로) |
| Notion | 설정 → 내보내기 → Markdown & CSV | 하위 페이지 계층, 이미지, 페이지 간 링크 |
| Markdown·HTML·텍스트 | 파일, 또는 폴더째 ZIP | 폴더는 상위 페이지로, 링크된 이미지·파일 업로드, `[[위키 링크]]` 연결, EUC-KR 문서·윈도우 한글 파일명 지원 |
| Pagehouse | 내보내기 ZIP | 전부 그대로 |

- 가져오기는 **새 페이지만 추가**하고 기존 페이지는 바꾸지 않습니다. 결과가 마음에 들지 않으면 휴지통으로 옮기고 다시 하면 됩니다.
- 끝나면 **확인할 항목**이 원인별로 나옵니다. 항목마다 무슨 뜻인지와 무엇을 하면 되는지가 적혀 있습니다.
  - 올리지 못한 50MB 초과 첨부
  - 업로드에 없던 파일
  - 다른 스페이스로 가는 링크
- Confluence의 작성자·날짜·댓글·권한·수정 이력은 옮겨지지 않습니다. CSV에는 사용자 이름이 없어서 @멘션이 "@사용자"로 보입니다.
- 수백 MB가 넘는 내보내기는 압축을 풀고 **폴더 선택**으로 고르세요.

## 내보내기

| 무엇을 | 어디서 | 형식 |
|---|---|---|
| 페이지 하나 | 페이지 **⋯ → 내보내기** | **PDF 저장 / 인쇄**(인쇄 창에서 "PDF로 저장"), **Markdown (.md)** |
| 페이지와 하위 페이지 | 페이지 **⋯ → 하위 페이지 포함…** | 내보내기 화면에서 Markdown 또는 HTML ZIP |
| 스페이스 전체 | 스페이스 메뉴 → **스페이스 내보내기…** | 내보내기 화면에서 Markdown 또는 HTML ZIP |

**두 ZIP 형식의 차이:**
- **Markdown ZIP**: 페이지 계층대로 폴더에 담긴 `.md` 파일과 첨부입니다.
- **HTML ZIP**: 압축을 풀고 `index.html`을 브라우저로 열면 서버 없이 페이지 트리·링크·이미지가 동작합니다.

**공통 사항:**
- 두 ZIP 모두 `pagehouse.json`이 들어 있어 Pagehouse로 그대로 다시 가져올 수 있습니다.
- 내가 볼 수 있는 페이지만 들어갑니다.
- 스페이스가 크면 파일을 만드는 데 몇 분 걸릴 수 있으니 그동안 내보내기 화면을 닫지 마세요.

## AI 에이전트 (MCP)

1. **내 계정 → API 토큰**에서 토큰을 만듭니다.
2. 화면에 나오는 명령을 Claude Code 같은 MCP 클라이언트에 붙여 넣으면 에이전트가 페이지를 검색·읽기·작성·댓글할 수 있습니다.

알아 둘 점:
- 에이전트는 **내 권한 그대로** 동작합니다.
- 토큰은 만들 때 한 번만 보입니다. 비밀번호처럼 다루고, 쓰지 않으면 폐기하세요.

## 관리자용

사이드바의 **관리**에는 탭이 일곱 개 있습니다(개요, 사용자, 그룹, SSO, 웹훅, 감사 로그, 브랜딩).

**개요:**
- **서버 상태**: DB 응답, 메모리, 서버 지연, 최근 요청과 서버 오류, 동시 편집, 대기 중인 알림. 문제가 있으면 맨 위에 경고([모니터링](monitoring.ko.md))
- 디스크와 **저장 한도** 대비 사용량
- 마지막 자동 백업, 콘텐츠 수, 일별 편집, 큰 파일
- **백업 정책**: 백업 주기, 보관 개수, 며칠 지난 백업을 지울지([자세히](install.ko.md#백업과-복원))

한도에 다다르면 새 파일은 올릴 수 없지만 글은 항상 저장됩니다.

**사용자:**

| 하려는 일 | 방법 |
|---|---|
| 초대 | **멤버 초대 링크** 또는 **관리자 초대 링크**를 만들어 전달. 7일 안에 한 번 쓸 수 있습니다 |
| 역할 변경 | 역할 열 |
| 접근 차단 | **비활성화**. 즉시 로그아웃됩니다. **활성화**하면 다시 들어올 수 있습니다 |
| 비밀번호 재설정 | **재설정 링크**(하루 동안 한 번) 또는 **임시 비밀번호**(바로 로그인, 첫 로그인 때 새 비밀번호 설정). 둘 다 기존 로그인은 모두 끊깁니다 |

**SSO:** 회사 계정(OpenID Connect, Keycloak으로 테스트)으로 로그인하게 합니다.
1. 화면에 나온 **리디렉션 URI**를 SSO 서비스에 등록합니다.
2. Issuer URL, Client ID, Client secret을 넣고 **연결 확인**을 누릅니다.
3. **SSO 켜기**를 누릅니다. 저장하는 즉시 적용되고, 로그인 화면에 버튼이 생깁니다.

처음 로그인할 때 계정을 만들지, 비밀번호 로그인을 허용할지도 여기서 정합니다. 서버 `.env`에 `OIDC_ISSUER`가 있으면 그 설정이 우선하고 화면은 읽기 전용입니다. 위키에서 로그아웃하면 SSO 서버에서도 로그아웃됩니다. SSO 서버 쪽 설정은 [SSO 연결 가이드](sso.ko.md)를 보세요.

**웹훅:** 페이지·댓글 이벤트를 다른 시스템(CI, 봇, 검색 색인 등)에 보냅니다.
1. **웹훅 추가**에서 이름, URL, 대상 스페이스(전체 또는 하나), 이벤트(페이지 생성·수정·삭제, 댓글 작성)를 정합니다.
2. 한 번만 보여 주는 **서명 시크릿**을 복사해 둡니다. 요청은 JSON `POST`이고 헤더에 `X-Pagehouse-Event`와 `X-Pagehouse-Signature: sha256=<본문을 시크릿으로 만든 HMAC-SHA256>`이 붙습니다. 받는 쪽에서 이 값으로 진짜 요청인지 확인하세요.
3. **테스트 보내기**를 누르면 `ping` 이벤트가 갑니다. 목록에서 마지막 전송 결과를 볼 수 있습니다.

접근 제한이 걸린 페이지는 보내지 않습니다. 수정 이벤트는 페이지당 10분에 한 번까지만 보냅니다. 전송에 실패하면 5초, 30초 뒤에 두 번 더 시도합니다.

**브랜딩:** Pagehouse 대신 우리 조직의 이름과 로고를 씁니다.
- **이름**은 브라우저 탭 제목이 되고, 로그인 화면, 사이드바 맨 위, 메일 제목(`[이름] …`)과 보낸 사람 이름(`SMTP_FROM`을 따로 정하지 않은 경우)에 나옵니다. 비워 두면 기본값으로 돌아갑니다.
- **로고**(PNG, JPG, WebP, GIF, 512 KB까지)는 로그인 화면과 사이드바에 나오고 파비콘으로도 쓰입니다. 정사각형 이미지가 가장 잘 보입니다. **기본값으로**를 누르면 원래 로고로 돌아갑니다.
- 바꾼 내용은 내 화면에는 바로 보이고, 다른 사람은 다음에 위키를 열 때 보입니다(최대 30초 걸릴 수 있음). 바꿀 때마다 감사 로그에 남습니다.

**그룹:** 사람을 묶어 두면 스페이스 역할과 페이지 제한을 그룹 단위로 줄 수 있습니다. 권한에 쓰이는 그룹은 지울 수 없습니다.

**감사 로그:**
- 기록되는 것: 로그인(실패 포함), 계정·그룹·권한 변경, 페이지 삭제·복원·이동, 내보내기, API 토큰 발급
- 작업 종류로 거를 수 있고 권한 변경은 무엇을 바꿨는지까지 남습니다.

자기 역할을 바꾸거나 자기 계정을 비활성화할 수는 없으므로 관리자가 적어도 한 명은 항상 남습니다.
