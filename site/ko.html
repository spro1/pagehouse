팀 문서는
우리 서버 안에

Pagehouse는 작은 회사와 팀이 자기 서버에 설치해 쓰는 팀 위키입니다. 주간보고, 회의록, 기술 문서를 망 밖으로 내보내지 않고 한곳에서 관리하세요.

Docker · PodmanKubernetes (Helm)폐쇄망 설치한국어 · English

이런 팀을 위해 만들었습니다

위키 하나 쓰는 데 계약, 사용자 수 계산, 외부 저장 승인까지 필요했다면.

비용이 부담되는 5~200명 조직

계약을 갱신할 때마다 사용자 수를 세지 않아도 됩니다. 라이선스 비용이 없습니다.

문서를 밖에 둘 수 없는 조직

보안 규정, 고객사 요구, 폐쇄망 때문에 SaaS를 쓸 수 없는 곳. 데이터는 전부 우리 서버에만 있습니다.

운영 인력이 따로 없는 팀

서버 한 대에 컨테이너 세 개. 설치, 업그레이드, 백업이 스크립트 하나로 끝납니다.

쓰기 편한 위키에 필요한 것들

Confluence에 익숙한 사람이 바로 쓸 수 있게 만들었습니다.

✍️

에디터

상단 서식 툴바와 / 블록 메뉴, 글자 색, 병합과 셀 색이 되는 표, 크기 조절과 캡션이 되는 이미지, 45개 언어 코드 강조, Mermaid 다이어그램, 패널, 할 일, @ 멘션.

💬

실시간 협업

상대 커서가 보이는 공동 편집, 본문 일부에 다는 인라인 댓글, 답글과 해결 처리, 비교와 복원이 되는 버전 이력.

🔎

검색

⌘K 빠른 검색과 전체 검색. 한국어 조사를 처리하고 댓글과 첨부 파일명까지 찾습니다. 스페이스, 작성자, 기간 필터.

🔒

권한

스페이스별 공개 범위와 사람·그룹 단위 역할, 페이지별 보기·편집 제한. 권한 밖의 문서는 검색, 첨부, 이력 어디에도 나오지 않습니다.

🗂️

정리

스페이스와 끌어서 옮기는 페이지 트리, 하위 페이지까지 복사, 라벨, 즐겨찾기, 팀 템플릿, 되살릴 수 있는 휴지통.

🔔

알림

멘션, 답글, 지켜보는 페이지 변경을 앱 안, 메일, 그리고 Slack·Mattermost·Teams 같은 채팅 웹훅으로 받습니다.

🔑

로그인

초대 링크로 만드는 계정, 또는 관리 화면에서 켜는 OpenID Connect SSO(Keycloak으로 테스트). 로그아웃하면 SSO 세션도 함께 끝납니다.

🔗

연동

서명된 JSON으로 페이지·댓글 이벤트를 보내는 웹훅, REST API와 개인 토큰, AI 에이전트용 MCP 서버.

📦

이관과 내보내기

Confluence(CSV·HTML), Notion, Markdown, HTML 가져오기. 스페이스를 Markdown이나 브라우저로 바로 여는 HTML ZIP으로 내보내기.

데이터는 우리 서버를 떠나지 않습니다

외부 글꼴, CDN, 원격 수집이 없습니다. 외부로 나가는 요청은 직접 켠 기능뿐입니다.

데이터 위치PostgreSQL과 파일 볼륨, 전부 우리 서버 안. 외부 요청은 직접 설정한 SSO, 메일, 웹훅과 링크 카드 미리보기뿐입니다(미리보기도 끌 수 있음).
인터넷 없는 환경컨테이너 이미지가 든 오프라인 번들로 설치하고 업그레이드합니다.
잃어버리지 않게삭제는 휴지통으로, 모든 수정은 버전 이력으로 남습니다. 매일 자동 백업하고, 업그레이드와 복원 전에도 백업합니다. 보관 정책은 관리 화면에서 정합니다.
보안로그인 시도 제한, 감사 로그(로그인 실패, 권한 변경, 삭제, 내보내기), 저장된 SSO·웹훅 시크릿 암호화, 내부망을 겨냥한 요청 차단.
떠날 때스페이스 전체를 Markdown이나 HTML로 내보낼 수 있어 데이터가 특정 형식에 묶이지 않습니다.

서버 한 대, 명령 한 줄

Docker 24 또는 Podman 4 이상이 있는 Linux 서버면 됩니다. 1 vCPU와 1GB 메모리로 시작할 수 있습니다.

인터넷이 되는 서버 가장 간단

DB 비밀번호와 암호화 키를 만들고, 이미지를 받아 서비스를 띄웁니다.

curl -fsSL https://github.com/spro1/pagehouse/releases/download/v0.2.0-beta.5/install.sh | sh -s -- --dir /opt/pagehouse --version 0.2.0-beta.5

폐쇄망

릴리스 페이지에서 오프라인 번들을 받아 서버로 옮긴 뒤 실행합니다. 아무것도 내려받지 않습니다.

tar xzf pagehouse-<버전>-offline-amd64.tar.gz
sh pagehouse-<버전>/install.sh --dir /opt/pagehouse

쿠버네티스

PostgreSQL, 매일 백업하는 CronJob, DB 비밀번호까지 함께 설치합니다.

helm install wiki pagehouse-<버전>.tgz -n wiki --create-namespace \
  --set ingress.enabled=true --set ingress.host=wiki.example.com

업그레이드는 설치 폴더에서 scripts/upgrade.sh <버전> 한 번이면 됩니다. 자세한 내용은 설치 가이드와 업그레이드 가이드를 보세요.

Confluence에서 옮겨 오기

스페이스를 내보낸 파일을 그대로 올리면 페이지 트리와 첨부가 따라옵니다.

내보내기

Confluence 스페이스 설정 → 내보내기에서 HTML이나 CSV로 받습니다.

가져오기

Pagehouse 홈 화면의 가져오기에 ZIP을 올립니다. 가져올 페이지를 미리 보고 확정합니다.

확인

페이지 순서, 폴더, 첨부, 라벨, 코드·패널·Jira 같은 매크로가 변환됩니다. 확인이 필요한 문서는 표시됩니다.

자주 묻는 질문

정말 무료인가요?

네. Apache-2.0 라이선스의 오픈소스이고 사용자 수 제한도 없습니다. 서버 비용만 듭니다.

몇 명까지 쓸 수 있나요?

2~4 vCPU, 4GB 메모리면 200명 정도까지 권장합니다. 더 큰 조직은 쿠버네티스에서 앱을 여러 대 띄우고 외부 PostgreSQL을 쓸 수 있습니다.

회사 계정(SSO)으로 로그인할 수 있나요?

네. OpenID Connect를 지원하면 관리 → SSO에서 바로 켤 수 있습니다. 지금까지 Keycloak과 연동을 테스트했습니다.

지금 써도 되나요?

현재 베타입니다. 기능은 실제 업무에 쓸 수 있는 수준이지만, 정식 버전 전까지 바뀌는 부분이 있을 수 있으니 업그레이드 전에 업그레이드 가이드를 확인하세요. 자동 백업이 기본으로 켜져 있습니다.

문제가 있거나 기능을 제안하고 싶어요.
